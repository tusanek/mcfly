# Снимки образцов командой mcfly (0.20.0)

Короткий проект. Одобрен владельцем 21.11.2026.

## Зачем

С 0.19.0 владелец одобряет планы по картинкам образцов. Снимать картинки должен был дизайнер через Playwright MCP, но в прогоне это не работает: Playwright MCP не открывает адреса `file:`, а поднять локальный http-сервер субагенту не даёт проверка разрешений. В прогоне 20.11 пять дизайнеров из семи остались без картинок, снимал лид вручную через `Chrome --headless --screenshot`.

Успех: дизайнер кладёт `design/samples/<изменение>/NN.html` и одной разрешённой командой получает картинки; без картинок владелец видит образцы текстом только при настоящем сбое.

## Что делаем

- `mcfly samples shoot <изменение>`: для каждого `design/samples/<изменение>/NN.html` (имя — цифры) снимает `NN-light.png` и, если образец поддерживает тёмную тему, `NN-dark.png` (страница с `?theme=dark`). Снимается элемент `#shot`, без него — вся страница; ширина окна 390.
- Съёмка — сам mcfly: запускает Chrome без окна (`--headless`) и управляет им через канал отладки по трубам (`--remote-debugging-pipe`, файловые дескрипторы 3 и 4) — без сетевого порта и без новых зависимостей.
- Браузер: `samples.browser` в config.yaml, иначе Google Chrome из `/Applications`, иначе Chromium из кэша Playwright (`~/Library/Caches/ms-playwright/chromium-*`). `mcfly doctor` проверяет, что браузер найден.
- Шаблон `.claude/settings.json` разрешает `Bash(mcfly samples shoot *)`.
- `mcfly approval request` сам вызывает съёмку, если у изменения есть HTML-образцы без картинок; строки «Картинка:» дописывает дизайнер.
- Тексты: designer.md, шаблон telegram-chat.html, подсказка `samples template` — «выполни `mcfly samples shoot <изменение>`» вместо «сними Playwright».
- Сбой — понятное сообщение (браузер не найден, страница не открылась, превышено время), код 1; образец остаётся текстом.

## Не делаем

- Снимки работающего приложения или сайта — только HTML-образцы.
- Перезапись готовых картинок без явного повтора команды: `approval request` снимает только недостающие, `samples shoot` — все.
- Новые npm-зависимости.

## Подходы

1. **Своя съёмка через канал отладки Chrome (выбран).** Без зависимостей, снимок ровно по элементу; около сотни строк кода и нужен Chrome или Chromium на машине.
2. Библиотека Playwright в mcfly. Меньше кода, но сотни мегабайт зависимости и привязка версии браузера к версии библиотеки — у других пользователей mcfly сложнее установка.
3. Только правило «снимай `Chrome --headless --screenshot`». Почти бесплатно, но Chrome так снимает весь экран, а не элемент, и каждый дизайнер подбирает размер окна сам.

## Решения исполнителя (мои)

- Тёмная тема поддерживается, если в HTML есть `theme=dark` или `.dark` в стилях; иначе снимается только светлая.
- Предел времени на страницу — 20 секунд.
- Если вызов из worktree: пути — от каталога, где лежит `design/samples/<изменение>` (текущий worktree), а не основного каталога.
