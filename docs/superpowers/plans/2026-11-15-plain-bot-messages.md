# Бот говорит простыми словами — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** убрать технические данные из всех сообщений бота Telegram и сделать пересказ прогона подробнее (0.9.0).

**Architecture:** формат отчёта меняется в инструкции репортёра (раздел «Простыми словами» из трёх абзацев до 1500 символов); сообщения собирают те же функции `src/summary.js`, `src/runner.js`, `src/overview.js`, `src/actions.js` — из них убираются технические строки. Технический хвост сводки выносится в отдельную функцию и печатается только в терминале.

**Tech Stack:** Node ≥ 20, `node --test`, без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-15-plain-bot-messages-design.md`

## Global Constraints

- В тексте для Telegram нет: `$`, «ходов», «субагент», «отказов разрешений», путей `mcfly/runs/…`, номера прогона, «(код N)», служебного имени изменения (кроме кнопок).
- Номера вопросов (Q4) и пунктов списка (I40) остаются: ими владелец отвечает боту.
- Длительность прогона остаётся.
- Старый отчёт с одним абзацем «Простыми словами» читается как раньше.
- Записи журнала `mcfly/progress.md`, `metrics.jsonl`, вывод `mcfly status` в терминале не меняются.

## Review Focus

- Прогон без отчёта репортёра (остановлен по времени или лимиту): итог объясняет причину словами, без пустых разделов.
- Изменение без пункта списка и без текста proposal: название — служебное имя (другого нет), сообщение не ломается.
- Пересказ длиннее сообщения Telegram: урезается пересказ, вопросы и одобрения остаются целиком.
- Сводка длиннее 4000 символов: делится на сообщения, кнопки под первым.
- Квота ровно 80 % — предупреждение есть; 79 % — строки нет.

### Task 2: общие помощники (`src/summary.js`)

**Produces:**
- `plainWords(sec, max = 1500): string` — абзацы «Что сделано / Зачем / Что дальше» с новой строки, остальное одним абзацем.
- `plainHtml(text): string` — экранирует и выделяет жирным начала абзацев.
- `changeTitle(p, c, esc, { short })` — без пункта списка: первая фраза proposal (до 80 символов, short — до 50), иначе имя.
- `progressWords(projectDir, c): string` — «сделано 1 из 2 шагов».
- `STATUS_RU`, `runsByStatus` — словами без жаргона.
- `QUOTA_WARN = 0.8`.

- [ ] Тесты в `test/summary.test.js` на каждую функцию, затем реализация.
